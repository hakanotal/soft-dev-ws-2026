# Data

## penguins.csv

Measurements of 344 penguins from three islands in the Palmer Archipelago, Antarctica, collected 2007 to 2009.

| Column | Meaning |
|---|---|
| `species` | Adelie, Chinstrap or Gentoo |
| `island` | Biscoe, Dream or Torgersen |
| `bill_length_mm` | Bill length in millimetres |
| `bill_depth_mm` | Bill depth in millimetres |
| `flipper_length_mm` | Flipper length in millimetres |
| `body_mass_g` | Body mass in grams |
| `sex` | male or female |
| `year` | Year of the observation |

Missing values are written as `NA` (19 cells across a few rows), so the analysis has to handle them.

**Source:** Horst AM, Hill AP, Gorman KB (2020). palmerpenguins: Palmer Archipelago (Antarctica) penguin data. https://allisonhorst.github.io/palmerpenguins/. Data originally collected by Dr. Kristen Gorman and the Palmer Station LTER.
